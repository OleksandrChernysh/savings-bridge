# Savings Bridge

[English version](README.md)

Простий помічник, який **економить ваші платні ліміти (токени) в Claude, Gemini або ChatGPT/Codex**.

Замість того щоб витрачати дорогу основну модель на кожну дрібницю (переклади, короткі відповіді, підсумки тексту, простий код, перевірку помилок), Savings Bridge автоматично направляє такі задачі на **безкоштовні хмарні моделі** або **локальні моделі на вашому комп'ютері** — і рахує, скільки ви вже зекономили.

---

## Що буде з вашою основною моделлю

- **Вона залишається на місці і працює як раніше.** Ви нічого не втрачаєте і не вимикаєте.
- **Складні задачі лишаються за нею.** Архітектура, важливі рішення, складне програмування та фінальна перевірка все одно виконуються вашою основною моделлю.
- **Прості задачі йдуть у фоновий помічник.** Звичайна текстова переписка, скорочення текстів, переклади, чернетки, ізольовані модулі коду (≥40 рядків), тести та повідомлення для Git виконуються безкоштовно; дрібні мікро-правки (≤15 рядків) лишаються в основній моделі, щоб не витрачати зайві токени на координацію.
- **Вбудований захист від перевитрат (anti-ping-pong).** `local_bridge.py code` сам підтягує локальні імпорти в контекст, запускає перевірку `--check` за замовчуванням, локально робить повторну спробу виправлення з урахуванням типів і відкочує файл при провалі — основна модель не витрачає токени на вичистку помилок.
- **Ваші паролі та приватні дані в безпеці.** Якщо в тексті або файлі є паролі, ключі чи `.env`, система блокує відправку у зовнішні безкоштовні сервіси — такі дані обробляються тільки локально на вашому комп'ютері або вашою основною моделлю.

## Що додатково встановиться на ваш комп'ютер

Під час запуску `python3 setup.py` на комп'ютері з'являться лише легкі текстові скрипти (без важких програм і сторонніх бібліотек Python):

1. **Скрипти помічника** у папку `~/.gemini/bin/` (`local_bridge.py`, `token_stats.py`, `cli_meter.py`, `metrics_server.py`, `model_discovery.py`) та інструкцію для вашого AI-агента (`skills/local-coder/SKILL.md`) для **Gemini / Antigravity** (`~/.gemini/antigravity/skills/local-coder/`), **Claude Code** (`~/.claude/skills/local-coder/`, якщо є `~/.claude/`) та **ChatGPT / Codex CLI** (`~/.codex/skills/local-coder/`, якщо є `~/.codex/`).
2. **Локальний менеджер ключів (файл `secrets.env`)** у `~/.config/savings-bridge/secrets.env` з правами доступу тільки для вашого користувача (`chmod 600`). Туди зберігаються API-ключі хмарних сервісів, які ви захочете підключити (цей крок можна пропустити, якщо користуєтесь лише локальними моделями).
3. **Профіль вашого комп'ютера** у `~/.config/savings-bridge/models.json` — список знайдених локальних моделей і автоматично підібраних налаштувань під вашу оперативну пам'ять (RAM).
4. **Журнал економії** у `~/.gemini/antigravity/local_tokens.jsonl` — сюди записується кількість зекономлених токенів.
5. **Опціонально (для роботи без інтернету):** якщо у вас ще не встановлена програма для запуску моделей на комп'ютері (наприклад, **Ollama** або **LM Studio**), інсталятор сам перевірить обсяг вашої RAM і підкаже, що саме завантажити. Сама Ollama/LM Studio автоматично не встановлюється — ви ставите її за бажанням.

## Що конкретно робить система

| Модуль | Що робить | Яку користь дає | Що перевіряє / читає | Що визначає автоматично |
|---|---|---|---|---|
| **Підбір моделей** (`model_discovery.py`) | Перевіряє ваш комп'ютер і доступні локальні моделі | Не потрібно розбиратися в технічних назвах моделей і гадати, чи вистачить пам'яті | Обсяг RAM, тип процесора, локальні порти Ollama (`:11434`) та LM Studio (`:1234`) | Операційну систему (macOS, Linux, Windows), оптимальні моделі для тексту та коду, або підказку що встановити |
| **Майстер налаштування** (`setup.py`) | Проводить просте покрокове налаштування за 1–2 хвилини | Можна швидко поставити на новий ноутбук або передати другу | Файл `providers.json`, локальні порти, введені вами ключі | Потрібні шляхи на вашій ОС, права доступу до ключів, безпечну резервну копію (`.bak`) перед оновленням файлів |

| **Помічник для коду** (`local_bridge.py code`, `review`, `git-commit`, `parse-json`) | Пише модулі, тести, витягує JSON із тексту, готує опис змін для Git | Розвантажує основну модель без пінг-понгу токенів | Вказані файли, авто-підтягнуті локальні імпорти, історію Git, налаштування мови | Автоматично додає імпортовані локальні типи, запускає `--check` (`tsc`, `swiftc`, `py_compile`, `php -l`), робить авто-ремонт і відкат при провалі |
| **Захист секретів** (`Zero-Secrets Guard`) | Перевіряє текст і назви файлів перед відправкою у зовнішні безкоштовні сервіси | Захищає від випадкового витоку паролів і ключів | Назви файлів (`.env`, `.pem`, `.key`) і текст запитів | Наявність токенів, ключів і паролів; при виявленні блокує відправку в зовнішні безкоштовні моделі |
| **Лічильник економії** (`token_stats.py`, `metrics_server.py`) | Рахує витрачені й зекономлені токени та віддає статистику у термінал, браузер або віджет | Наочно показує, скільки токенів вдалося зберегти за день, тиждень чи місяць | Журнал `local_tokens.jsonl` та історію діалогів агента | Відсоток економії окремо для текстового спілкування та для коду, а також статус локальних програм |

## Як подивитися свою економію (день, тиждень, місяць)

Відкрийте термінал і виконайте потрібну команду:

```bash
# Економія за останній день (сьогодні)
python3 ~/.gemini/bin/token_stats.py --period day

# Економія за останній тиждень (7 днів)
python3 ~/.gemini/bin/token_stats.py --period week

# Економія за останній місяць (30 днів)
python3 ~/.gemini/bin/token_stats.py --period month
```

### Веб-сторінка та дані для віджетів

Запустіть локальний сервер лічильника:
```bash
python3 ~/.gemini/bin/metrics_server.py --port 4040
```
Після запуску доступні адреси:
- `http://127.0.0.1:4040/` — проста сторінка в браузері зі статистикою економії
- `http://127.0.0.1:4040/metrics/summary?period=day` (або `week`, `month`) — дані у форматі JSON для віджетів (SwiftBar, Waybar, Raycast, PowerShell)
- `http://127.0.0.1:4040/health` — перевірка, чи запущені локальні моделі

## Як встановити (1 команда для macOS, Linux і Windows)

```bash
git clone https://github.com/OleksandrChernysh/savings-bridge.git savings-bridge && cd savings-bridge
python3 setup.py
```

Додаткові режими:
- `python3 setup.py --dry-run` — подивитися, що зробить програма, без реальних змін на диску
- `python3 setup.py --skip-keys` — встановити без введення хмарних ключів (тільки для локальних моделей)

`local_bridge.py` автоматично підхоплює `~/.config/savings-bridge/secrets.env` на macOS, Linux та Windows. Якщо ці ключі також потрібні іншим інструментам у терміналі на macOS/Linux:
```bash
source ~/.config/savings-bridge/secrets.env
```

## Приклади використання

```bash
# 1. Текстовий запит через безкоштовну хмарну модель
python3 ~/.gemini/bin/local_bridge.py ask -p "Скороти цей лист до 3 головних пунктів" -c letter.txt

# 2. Текстовий запит локально на вашому комп'ютері (без інтернету)
python3 ~/.gemini/bin/local_bridge.py ask -m fast -p "Переклади цей текст українською"

# 3. Проста задача з кодом (модель підбирається автоматично під ваш комп'ютер)
python3 ~/.gemini/bin/local_bridge.py code -m coder -f helper.ts -c types.ts --check -p "Додай перевірку email"

# 4. Перевірити, які моделі система підібрала під ваш комп'ютер
python3 ~/.gemini/bin/local_bridge.py models
```
